# Bus Reservation System

A lightweight web application built using Java Web Technologies to automate bus ticket booking processes, handle seat allocation, and manage passenger records.

## 🛠️ Tech Stack
* **Backend:** Java (Servlets & JSP)
* **Database:** MySQL
* **Server:** Apache Tomcat
* **Frontend:** HTML, CSS, JavaScript

## 🚀 Key Features
* **Authentication:** Secure passenger registration and login system.
* **Bus Management:** Real-time bus search based on routes and schedules.
* **Ticket Booking:** Interactive seat selection and reservation tracking.

## 📁 Project Structure
* `src/` - Contains Java Servlet files (Backend Logic)
* `WebContent/` (or `webapp/`) - Contains HTML, CSS, and JSP files (UI)
* `database.sql` - Database schema and table configurations
## ⚡ How to Run
1. Clone the repo
2. Import `database.sql` into MySQL
3. Deploy on Apache Tomcat 9/10
4. Open `http://localhost:8080/BusReservationSystem`
